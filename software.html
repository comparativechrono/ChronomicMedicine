Clinical genetics

Pedigree Studio

Draw clinical genetics pedigrees in a web browser. Pedigree Studio is a single HTML file that works offline, and no data leaves the device, so it can be used where online tools can’t: in prisons, rural clinics and home visits, and wherever patient data mustn’t go to an outside server.

It is also useful for teaching, as students can practise drawing pedigrees without accounts or any setup.

Open Pedigree Studio GitHub Zenodo

Python packages for Pedigree Studio files

Convert pedigrees between Pedigree Studio, PED files, the GA4GH Pedigree standard and Phenopackets, and standardise their disease and phenotype terms. Each package installs with pip.

Time-course data

nugap

A Python package that finds which genes, or which relationships between them, change their dynamics between two conditions, such as wild type and mutant. It uses the Vinnicombe ν-gap, a distance between dynamical systems from control theory, and its results have been checked against MATLAB’s implementation.

$ pip install nugap

Bioinformatics workbench

A workbench in the browser for bioinformatics practicals: Python and R notebooks, a Linux terminal with real bioinformatics programs, Galaxy, public databases, a genome browser, a 3D structure viewer and a network viewer.

Everything runs in the student’s browser. There is nothing to install and no server, and students’ files stay on their own computer.
