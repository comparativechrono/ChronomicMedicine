# Member Photos

Place headshot photos here. The filename must match the `photo` field in `data/members.csv`.

**Naming convention:** `firstname-lastname.jpg` (lowercase, hyphens)

**Examples:**
- `tim-hearn.jpg`
- `millie-ampiah.jpg`
- `bethan-lloyd-owen.jpg`

**Recommended specs:**
- Square crop (1:1 aspect ratio)
- Minimum 400×400px
- JPEG format
- File size under 200KB (compress with TinyJPG or similar)

If no photo is found, a monogram with the member's initials is shown instead.
